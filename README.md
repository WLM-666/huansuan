# 换算一下

适配 iPhone 的中文单位换算网页。支持长度、重量、温度、面积、体积（含美制单位）、速度和压力；数值框可双向即时换算。顶部的自然语言识别可理解常见英文单位、数字和包含多个计量值的英文句子，并为词库内单位显示中文含义与常见用途。常见词汇识别及换算在本机完成，首次联网打开后可离线使用。

## 发布到 GitHub Pages（免费）

1. 在电脑浏览器登录 GitHub，选择 **New repository**，创建一个公开仓库，例如 `huansuan`。
2. 选择 **Add file → Upload files**，把本目录内的 `index.html`、`styles.css`、`app.js`、`manifest.webmanifest`、`sw.js`、`icon.svg` 上传到仓库根目录并提交。
3. 打开仓库 **Settings → Pages**。在 **Build and deployment** 下选择 **Deploy from a branch**；分支选 `main`，目录选 `/(root)`，点 **Save**。
4. 等待 Pages 显示发布成功，访问 `https://你的GitHub用户名.github.io/huansuan/`。若仓库名称不同，把网址末尾换成仓库名称。首次打开需要联网。

## 添加到 iPhone 主屏幕

1. 在 iPhone 上用 **Safari** 打开已发布的网址，等待页面加载完成。
2. 点 Safari 底部的**分享**按钮（方框上箭头）；向下滚动并点 **添加到主屏幕**。
3. 名称可保留“换算一下”，点右上角**添加**。首次联网打开后会缓存页面文件，以后从主屏幕打开可离线使用常见单位识别与换算。

## 拍照识别说明

点“拍照 / 选取照片”可以直接调用 iPhone 相机或选择商品/尺寸照片。若浏览器提供本机 `TextDetector`，网页会尝试在本机识别照片文字并提取单位。iPhone Safari 当前通常不开放网页直接调用系统实况文本的接口，所以无法保证照片自动 OCR；这时可在 iPhone“照片”里打开图片，用系统**实况文本**复制尺寸，再粘贴到网页识别框。图片预览只在本机处理，不会上传。

词库外的生僻单位会明确提示未收录并请求补充上下文；网页不会随意猜译。当前没有接入在线翻译或云端 OCR，因此未收录单位和不支持网页 OCR 的图片无法自动识别。GitHub Pages 提供 HTTPS，这是离线缓存所需条件。
